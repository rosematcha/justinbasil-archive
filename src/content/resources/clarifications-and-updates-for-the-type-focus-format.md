<div class="sqs-html-content" data-sqsp-text-block-content="">
  <p class="" style="white-space:pre-wrap;">The description of the Type Focus format has been updated ahead of the Type Focus–Fairy format tournament on April 9th. Please be aware of the following changes to the format:</p><p class="" style="white-space:pre-wrap;">Two exceptions have been made with regard to permitting types other than the assigned Type Focus format.</p><p class="" style="white-space:pre-wrap;"><strong>Exception 1</strong>: Pokémon of the focus type whose pre-evolutions have <em>no other available</em> types may be used if and only if their Type Focus typed evolution is present in the deck. However, the use of these pre-evolutions counts against the deck's number of permitted Colorless Pokémon. (For example a Type Focus–Fairy deck <em>could</em> include 4 copies of Alolan Vulpix GRI 21, a Water type, and 4 copies of Alolan Ninetales CEC 145, but in order to include a copy of Ditto {*} LOT 154, the deck would need to include a fifth Fairy-type Pokémon card.) </p><p class="" style="white-space:pre-wrap;"><strong>Exception 2</strong>: Pokémon with multiple printed types. So long as one of the types printed on the card is the assigned focus type, the card is permitted. For example, M Gardevoir STS 79 is both Psychic and Fairy type. This means that the card is legal for use in both the Type Focus–Fairy and Type Focus–Psychic formats. These Pokémon simply count as the assigned type in their corresponding Type Focus formats.</p>

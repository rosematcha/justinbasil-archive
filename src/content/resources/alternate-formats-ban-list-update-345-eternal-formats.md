All of the following ban list updates are effective immediately.

Two cards have been added to the ban list for the 345 format: [Slowbro PGO 20](https://limitlesstcg.com/cards/PGO/20) and [Ambipom PGO 57](https://limitlesstcg.com/cards/PGO/57).

Additionally, two cards have been added to the ban list for the Eternal format and one card has been removed from the format’s ban list.

The following cards are now banned in the Eternal format:

- [Psyduck FO 53](https://pkmncards.com/card/psyduck-fossil-fo-53/)
- [Double Gust N1 100](https://pkmncards.com/card/double-gust-neo-genesis-n1-100/)

<div class="jb-gallery"><figure class="jb-gallery-slide"><a href="/images/b0ba2901fb9c1d13.webp"><img src="/images/b0ba2901fb9c1d13.webp" alt="double-gust-neo-genesis-100.jpg" loading="lazy"></a></figure><figure class="jb-gallery-slide"><a href="/images/4b263002e79226ef.webp"><img src="/images/4b263002e79226ef.webp" alt="psyduck-fossil-fo-53.jpg" loading="lazy"></a></figure></div>

Note that because the Black Star Promo 20 version of Psyduck is a reprint of the Psyduck from Fossil, it is also banned by that card’s ban.

<div class="jb-gallery"><figure class="jb-gallery-slide"><a href="/images/e5a951ee9533506d.webp"><img src="/images/e5a951ee9533506d.webp" alt="psyduck-wizards-black-star-promos-20.jpg" loading="lazy"></a></figure></div>

The following card is no longer banned in the Eternal format:

- [Pokémon Center BS 85](https://pkmncards.com/card/pokemon-center-base-set-bs-85/)

<div class="jb-gallery"><figure class="jb-gallery-slide"><a href="/images/12b8cc34f7249f5c.webp"><img src="/images/12b8cc34f7249f5c.webp" alt="pokemon-center-base-set-bs-85.jpg" loading="lazy"></a></figure></div>

Note that this card, like other cards with newer prints, must be played with the newest text printed on any card of the same name. In this case, [Pokémon Center’s newest print](https://limitlesstcg.com/cards/NXD/90) comes from *Black & White—Next Destinies* and the Base Set version of the card (and all prints prior to that *Next Destinies* print) must be played with the newest text.

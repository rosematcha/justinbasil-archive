<div class="sqs-html-content" data-sqsp-text-block-content="">
  <p class="" style="white-space:pre-wrap;">The Pokémon Trading Card Game Classic is a self-contained game in a box featuring special holofoil versions of various cards from throughout the life of the Pokémon Trading Card Game and a handful of new cards like Ho-oh ex, Suicune ex, and Lugia ex. Pokémon Trading Card Game Classic contains three decks centered around Base Set Venusaur (CLF), Base Set Charizard (CLL), and Base Set Blastoise (CLK). Per Pokémon’s official announcement of The Pokémon Trading Card Game Classic, <strong>no cards contained within this product will be legal for tournament play, except for the product’s basic energy cards</strong>.</p><h2 style="white-space:pre-wrap;">The Decks</h2>

<h1 class="jb-center">What We Know About</h1>

<div class="jb-row"><div class="jb-col-4"></div><div class="jb-col-4">

![](/images/pokemon-trading-card-game-classic-logo.webp)

</div><div class="jb-col-4"></div></div>

The Pokémon Trading Card Game Classic is a self-contained game in a box featuring special holofoil versions of various cards from throughout the life of the Pokémon Trading Card Game and a handful of new cards like Ho-oh ex, Suicune ex, and Lugia ex. Pokémon Trading Card Game Classic contains three decks centered around Base Set Venusaur (CLF), Base Set Charizard (CLL), and Base Set Blastoise (CLK). Per Pokémon’s official announcement of The Pokémon Trading Card Game Classic, **no cards contained within this product will be legal for tournament play, except for the product’s basic energy cards**.

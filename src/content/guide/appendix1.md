<div class="sqs-html-content" data-sqsp-text-block-content="">
  <p class="" style="white-space:pre-wrap;">All throughout this guide, you’ll see a card name followed by a set of two to three letters and a number, like these examples below:</p><p style="text-align:center;white-space:pre-wrap;" class="">Energy Retrieval BS 81<br>Blacephalon-GX LOT 52<br>Boss’s Orders RCL 154</p><p class="" style="white-space:pre-wrap;">This is the most common way for players to specify which card they’re referring to when discussing their decks and the cards in them. The letters are the official <strong>Set Abbreviation</strong>—or the shorthand used to refer to a specific <strong>Set</strong>—also called an <strong>Expansion</strong>. The Pokémon Company International releases four main expansions each year—typically in February, May, August, and November—in additional to an annual miniset that usually releases between August and October. You’ll recognize these sets by their names on the booster packs you open—Brilliant Stars, Astral Radiance, and Lost Origin are all examples of these sets and each has its own Set Abbreviation. You can review a list of these abbreviations below.</p><p class="" style="white-space:pre-wrap;">The number after the Set Abbreviation refers to the <strong>Collector Number </strong>on the card—or the number printed on the card that represents its position in the set. You can see this collector number on the bottom of each card, usually followed by a slash and the total number of cards in the set, excluding secret rares. So, let’s say we want to refer to a specific Sprigatito from the expansion <em>Scarlet &amp; Violet.</em></p><p class="" style="white-space:pre-wrap;">We can see that Sprigatito’s Collector Number is 13—it’s card 13 of 198 in its set. Using the list of symbols and abbreviations below, we can see that its <strong>Set Identifier</strong>—the text in the box next to the card’s collector number—means that it comes from the set <em>Scarlet &amp; Violet, </em>which is abbreviated as SVI<em>. </em>Sets released prior to <em>Scarlet &amp; Violet </em>base set will have a <strong>Set Symbol</strong> instead of a set identifier.</p><p class="" style="white-space:pre-wrap;">So, if we wanted to refer to this specific Sprigatito, we can do just that by writing Sprigatito SVI 13. Now, other players will know exactly which Sprigatito we’re referring to.</p><p class="" style="white-space:pre-wrap;">Note that card legality is no longer strictly determined by the set a card was printed in. Below is a rough guide to help you gauge which of your cards will be legal to play in the Standard format. In the image of the Sprigatito above, you’ll note the letter “G” in a box. This box is called a <strong>Regulation Mark </strong>and helps players understand which cards are currently legal in the Standard format.</p>
